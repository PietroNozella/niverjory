# Operacao Borahae: Missao Aniversario

Cartao de aniversario interativo em formato de missao diplomatica secreta, feito com Next.js, TypeScript, Tailwind CSS, Framer Motion, lucide-react e canvas-confetti.

## Rodar localmente

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.

## Customizar

Edite `src/data/mission.ts` para alterar:

- nome da amiga
- textos introdutorios
- perguntas e respostas aceitas
- tratados da amizade
- mensagem final

## Deploy na Vercel

1. Suba este projeto para um repositorio no GitHub.
2. Na Vercel, clique em `Add New Project`.
3. Importe o repositorio.
4. Mantenha os comandos padrao:
   - Install Command: `npm install`
   - Build Command: `npm run build`
   - Output: Next.js default
5. Clique em `Deploy`.
